# E-Commerce Sales Analysis — Python

**Data analytics portfolio practice project (synthetic data).**

Analyze sales using Python and Pandas: clean and validate an orders table, calculate net revenue after discounts, exclude cancelled orders, and compare revenue by month, category, and region.

Run: `pip install pandas matplotlib` then `python analyze.py` after saving an orders CSV as `data/synthetic_orders.csv`.

Dataset schema: `order_id,order_date,customer_id,product,category,region,quantity,unit_price_sar,discount_rate,order_status`.

**Status:** reproducible code added; full synthetic example CSV and visual outputs are included in the downloadable bundle prepared for this project, but are not uploaded to this GitHub folder yet. No real business results are claimed.
