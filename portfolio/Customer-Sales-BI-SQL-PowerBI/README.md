# Customer & Sales Performance — SQL / Power BI

**Business intelligence portfolio practice project using synthetic data.**

SQL analyzes completed-order revenue by month, category, customer and region. `build_db.py` creates a demo SQLite database from an orders CSV with the same schema as the Python project. `sql/analysis.sql` contains four repeatable queries.

**Power BI status:** planned, not yet built; no PBIX dashboard is claimed.

Suggested dashboard: KPI cards for revenue, orders, AOV, customer count; revenue trend; region/category charts; date slicer.
